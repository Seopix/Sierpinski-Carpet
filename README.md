# Sierpinski Carpet - WebGL

WebGL을 사용하여 Sierpinski Carpet을 구현한 컴퓨터그래픽스 과제입니다.

## Features

- Sierpinski Carpet 재귀 분할 구현
- Slider를 이용한 분할 횟수 조절
- Select 메뉴를 이용한 색상 변경
- Reset 버튼을 이용한 초기 상태 복원

## Tech Stack

- HTML
- JavaScript
- WebGL
- GLSL
